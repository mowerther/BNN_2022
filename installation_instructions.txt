# 1. Create an Anaconda environment (assuming Anaconda is installed and configured) with Python 3.12:
conda create -n bnn_2022_env python=3.12
# 2. After creation of the environment type:
conda activate bnn_2022_env
# 3. Install the tested stable package set:
pip install -r requirements-python-3.12.txt
# The original trained models remain unchanged. The current code applies stored fitted scaler parameters with NumPy instead of loading the historical scikit-learn pickle files.
# TensorFlow and TensorFlow Probability are installed with pip. The repository sets TF_USE_LEGACY_KERAS=1 before importing TensorFlow. If another part of an application imports TensorFlow first, set this environment variable before starting Python.
# 4. The BNNs for OLCI and MSI (require Rrs derived through prior AC) can be used with in situ data (i.e. 2D) and satellite data in netcdf format (.nc, i.e. 3D).
